# GIVE MEP Equipment

Multilingual industrial equipment showcase built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Local development

Run `pnpm install`, then `pnpm dev`, and open http://localhost:3000. The root URL redirects to English; Chinese and French are available at `/zh` and `/fr`.

## Checks

Run `pnpm lint` and `pnpm build`.

## Asset folders

Keep approved assets in `public/logo`, `public/products`, `public/projects`, and `public/certificates`.
